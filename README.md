# Dockerized-Full-Stack-ToDo-Application
Using Docker and node.js, creating a loaded enviornment

Technologies: Docker, Node.js, MySQL, Linux, Docker Hub, Networking

This project focused on building and deploying a containerized full-stack Todo application using Docker, Node.js, and MySQL within Linux-based development environments. The application was deployed using Docker containers to isolate backend services and database environments while supporting persistent data storage and local container networking. Docker commands and container management workflows were used to build images, manage running containers, inspect application logs, expose application services through mapped ports, and interact with database containers using MySQL command-line tools. The project also involved working with Docker Hub repositories, containerized application deployment workflows, and backend service management concepts commonly used in modern cloud-native and DevOps environments.
